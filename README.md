# Game Tracker

Game Tracker, video oyunlarını ve oynama durumlarını takip etmek için geliştirilmiş bir React uygulamasıdır. Kullanıcılar oyun ekleyebilir, eklenen oyunları listeleyebilir, güncelleyebilir ve silebilir.

## Özellikler

- Yeni oyun ekleme
- Oyunları listeleme
- Oyun bilgilerini güncelleme
- Oyun silme
- Oyun durumunu belirleme
- Verileri LocalStorage üzerinde saklama
- Farklı ekran boyutlarına uyumlu tasarım

## Kullanılan Teknolojiler

- React
- JavaScript
- Vite
- Pure CSS
- LocalStorage

## Kurulum

Projeyi bilgisayarınıza klonlayın:

```bash
git clone https://github.com/senaa04/sena-yolcu-game-tracker.git
```

Proje klasörüne girin:

```bash
cd game-tracker
```

Gerekli paketleri yükleyin:

```bash
npm install
```

Uygulamayı çalıştırın:

```bash
npm run dev
```

Terminalde gösterilen yerel bağlantıyı tarayıcıda açın.

## Kullanım

1. Oyun adını girin.
2. Platform bilgisini girin.
3. Oyunun durumunu seçin.
4. **Oyun Ekle** butonuna basın.
5. Eklenen oyunları **Düzenle** veya **Sil** butonlarıyla yönetebilirsiniz.
